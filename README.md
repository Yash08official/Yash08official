## About

I’m a Computer Science Engineer and Full-Stack Developer who enjoys building software from the user interface down to the API and database.

My hands-on development experience spans **React, JavaScript, Node.js, Express, MongoDB, Java, and blockchain applications**. My current engineering direction is **React.js on the frontend and C# / ASP.NET Core on the backend**, with a strong focus on API development, authentication, data access, and maintainable application design.

I like understanding the complete request lifecycle: how a client sends data, how an API validates and processes it, how persistence works, and how security and error handling fit together.

- **Primary direction:** Full-Stack / Backend Development
- **Frontend:** React.js, JavaScript, TypeScript, HTML, CSS, Tailwind CSS
- **Backend:** C#, .NET, ASP.NET Core Web API, Node.js, Express.js
- **Data:** SQL Server, Entity Framework Core, MongoDB, MySQL
- **Engineering practice:** REST APIs, JWT authentication, refresh tokens, claims, role-based authorization, Postman testing
- **Education:** B.E. Computer Science & Engineering — Sipna College of Engineering & Technology (2024)
